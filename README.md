## 📖 Описание

Incident Inbox Frontend — это инструмент для работы с инцидентами, разработанный с учетом современных требований к производительности и пользовательскому опыту.

### ✨ Основные возможности

<div align="center">

| | Функционал | Описание |
|---|------------|----------|
| 📊 | **Пагинация** | Навигация по страницам с настраиваемым размером |
| 🔍 | **Поиск** | Поиск по ID, заголовку и описанию, с debounce |
| 🏷️ | **Фильтрация** | Фильтрация по статусу и приоритету |
| ⬆️ | **Сортировка** | Сортировка по дате инцидента |
| ✅ | **Массовые операции** | Групповое изменение статуса и приоритета |

</div>

## 🚀 Быстрый старт

### Предварительные требования

- [Bun](https://bun.sh) (версия 1.0.0 или выше)

### Установка и запуск

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd incident-inbox-frontend

# Установка зависимостей
bun install

# Запуск в режиме разработки
bun dev
```

После запуска приложение будет доступно по адресу **http://localhost:5173**

### 📦 Доступные скрипты

| Команда | Описание |
|---------|----------|
| `bun dev` | Запуск в режиме разработки с hot reload |
| `bun build` | Сборка production версии |
| `bun preview` | Предпросмотр production сборки (Моки работают только в Dev режиме) |
| `bun test` | Запуск тестов |
| `bun test --watch` | Запуск тестов в режиме отслеживания изменений |
| `bun lint` | Проверка кода линтером |
| `bun format` | Автоматическое форматирование кода |
| `bun typecheck` | Проверка типов TypeScript |

## 🧪 Тестирование

Проект использует **Vitest** для модульного тестирования и **Happy-DOM** для эмуляции браузерного окружения.

```bash
# Запуск всех тестов
bun run test

# Запуск с покрытием кода
bun run test --coverage

# Запуск конкретного теста
bun run test src/features/incidents
```
